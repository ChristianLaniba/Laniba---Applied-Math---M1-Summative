Controls: <br>
WASD (Move) | X (Rotate) | Y (Scale - Grow), Shift-Y (Scale - Shrink) | K (Change Speed Modes) | Mouse (Camera) | Esc/P (Pause) <br>

Tips for each level: <br>

Level 1: Bigger size and speed can walk over pits <br>
Level 2: Bigger size and slower speed reduces slipperiness.<br>
Level 3: Shield can block fire projectiles.
